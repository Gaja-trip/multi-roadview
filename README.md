# 로드뷰 타임 1.1

같은 장소의 과거와 현재를 **하나의 비교 영역**에서 보는 웹·Windows 프로그램입니다. 카카오맵 원본 로드뷰를 사용하므로 **카카오 JavaScript 키 없이 실행**됩니다.

## 사용하기

1. 왼쪽 **위치** 탭에서 주소·장소명, WGS84 위도·경도 또는 카카오맵 링크로 이동합니다. 최근 위치와 저장한 위치도 이 탭에 있습니다.
2. **비교** 탭에서 **2분할 / 4분할**, **분할 / 겹침**을 설정합니다. 오른쪽 위 비교 설정 버튼으로 이 탭을 바로 열 수 있습니다.
3. 각 화면의 **촬영일 선택**으로 실제 과거 사진을 고릅니다. 웹과 Windows 앱의 선택 방법은 아래와 같습니다.
4. **시기** 탭에서는 화면별 시기 이름을 직접 적거나 카카오맵 링크를 지정할 수 있습니다. 직접 적은 이름은 표시용이며 사진을 바꾸지 않습니다. 실제 촬영일은 원본에 표시된 날짜로 확인하세요.
5. **메뉴 숨기기 / 메뉴 보이기** 또는 왼쪽 메뉴 상단 접기 버튼으로 패널을 접고 펼칩니다. 선택한 탭·분할 수·패널 접힘 상태는 이 브라우저 또는 PC에 저장됩니다.

**겹침**에서는 같은 크기의 로드뷰를 포개고 가로·세로 경계 또는 가운데 손잡이(4분할)를 움직입니다. 아래 슬라이더와 방향키도 사용할 수 있습니다.

## 실제 촬영일 선택

- **웹:** 각 화면의 **촬영일 선택**을 누르면 해당 카카오맵 원본을 크게 표시합니다. 원본의 촬영일·시계 메뉴에서 과거 사진을 선택하세요. 원본이 과거·현재 비교로 열리면 원본의 비교 경계를 끝으로 옮겨 원하는 시기만 볼 수 있습니다. **비교로 돌아가기**로 여러 화면에 복귀합니다.
- **Windows 앱:** 각 화면의 **촬영일 선택**을 누르면 그 화면의 카카오맵 원본에서 제공하는 촬영일 목록을 읽어 표시합니다. 날짜를 고르면 같은 원본 화면의 날짜 선택 메뉴를 통해 사진을 전환하고 표시된 촬영일을 확인합니다. 목록이 바뀌었거나 위치를 이동했다면 목록을 다시 열어 선택하세요. 원본의 촬영일·시계 메뉴로 직접 조작할 수도 있습니다.

과거 사진은 카카오맵 원본에서 실제 제공하는 목록을 통해 선택합니다. 과거 사진의 내부 식별자를 일반 지도 링크에 넣는 방식은 사용하지 않습니다. 공유 링크가 선택한 과거 촬영분을 유지한다고 가정하지 말고 원본의 실제 촬영일을 확인하세요.

시점 A·B·C·D는 분할·겹침·크게 보기 전환 시 다시 생성하지 않으므로 선택한 화면을 유지합니다. 2분할에서 감춘 C·D도 4분할로 돌아오면 유지됩니다. 모든 화면의 위치를 이동하면 이전 시기 표시를 초기화합니다. 페이지를 다시 열면 화면별 링크와 시기 표시는 초기화됩니다.

## 자동 회전 연동

**Windows 앱**에서는 비교 탭의 **자동 회전**을 켜면 어느 화면을 조작하든 나머지 화면도 함께 회전합니다. **2분할은 180°**, **4분할은 90°** 간격을 유지하며 위아래 시선과 확대도 함께 맞춥니다. 화면마다 선택한 과거 촬영일은 유지합니다. 자동 회전 체크를 끄면 각 화면을 따로 조절할 수 있습니다. 카카오 JavaScript 키나 브라우저 확장 프로그램은 필요하지 않습니다.

**일반 웹 브라우저**에서는 원본 로드뷰를 표시하고 촬영일을 직접 선택할 수 있지만, 외부 카카오맵 iframe의 방향을 읽거나 변경할 수 없어 각 화면의 방향과 확대를 직접 조절합니다. 자동 회전 연동을 사용하려면 아래 Windows 앱을 실행하세요.

Windows의 자동 연동은 카카오맵 원본이 이미 생성한 로드뷰 인스턴스의 시점을 읽고 변경합니다. 별도 비공개 네트워크 API를 호출하거나 다른 서비스의 API 키를 복사하지 않습니다. 원본의 내부 연결 방식이 바뀌면 연동이 중단될 수 있으며, 앱에 표시되는 연결 상태를 확인하고 원본 화면에서 직접 조절할 수 있습니다.

## 웹 실행 및 Vercel 배포

```powershell
node scripts/preview.mjs
# http://127.0.0.1:4173
node scripts/build-web.mjs
```

저장소를 Vercel 프로젝트에 연결하고 재배포하세요. 루트의 `vercel.json`이 웹 빌드와 `dist` 출력, `/api/search` 서버 함수를 설정합니다. 웹 빌드는 Electron 설치 없이 실행됩니다. 프로젝트 Root Directory는 이 저장소 루트로 지정하세요. 배포 파일은 `dist`만 수동 업로드하면 주소 검색 함수가 빠지므로 **전체 저장소로 배포**해야 합니다.

웹과 Windows 앱 모두 HTTPS 카카오맵 원본을 iframe으로 표시합니다. Windows 앱은 로컬 파일에서 화면을 열며, 날짜 선택은 Electron이 이름으로 구분한 원본 프레임의 실제 날짜 메뉴를 조작하고 자동 회전은 해당 원본의 기존 로드뷰 인스턴스를 연결합니다. 원본 화면의 구성이 바뀌거나 네트워크가 차단되면 표시·날짜 선택·자동 연동이 달라질 수 있습니다.

## Windows 실행

`release/RoadviewTime-v1.1.0-win32-x64/RoadviewTime.exe`를 실행하세요. 실행 폴더 전체를 보관해야 합니다. 기존 실행 파일은 자동 업데이트되지 않습니다.

개발 환경에서는 Node.js 22.12 이상과 pnpm으로 다음 명령을 사용합니다.

```powershell
pnpm install
pnpm start
pnpm test
pnpm test:rotation # 인터넷에 연결된 실제 앱에서 드래그·과거 촬영일 검증
pnpm check
pnpm build
pnpm package
```

설치한 개발 폴더의 `로드뷰 타임 실행.cmd`로도 실행할 수 있습니다. Electron 바이너리가 없으면 `node node_modules/electron/install.js`로 설치합니다.

## 주소 검색 설정

기본 검색은 OpenStreetMap Nominatim과 대표 장소 바로 가기를 사용합니다. 국내 검색 결과가 없으면 좌표·카카오맵 링크로 이동하거나 카카오 REST 검색을 연결하세요. **REST API 키는 주소 검색용 선택 사항이며 로드뷰에는 필요하지 않습니다.**

- Windows: 왼쪽 아래 **주소 검색 연결 설정**에 본인 카카오 REST API 키를 입력합니다. Windows 계정으로 암호화해 저장합니다.
- Vercel: 프로젝트의 환경 변수 `KAKAO_REST_API_KEY`에 본인 REST API 키를 설정하고 재배포합니다. 서버에서만 사용하며 웹 번들에는 포함하지 않습니다.

공개 기본 검색은 수동 검색에만 사용하며, 캐시와 인스턴스별 요청 간격을 적용합니다. 여러 사용자가 동시에 사용하는 공개 서비스에는 계약한 검색 서비스 또는 자체 검색 서버를 연결하세요.

최근·저장 위치는 현재 브라우저 또는 PC에 보관됩니다. 위치 링크 복사는 좌표·지도 링크를 복사하며 각 시점에서 선택한 촬영일을 저장하지 않습니다.

## 원본 데이터

촬영일·과거 사진·촬영 지점은 카카오맵 원본에서 실제 제공하는 범위만 이용합니다. Windows 앱의 날짜 목록은 원본 화면에 표시되는 날짜 선택 메뉴에서 읽습니다. 제공되지 않는 과거 사진이나 날짜를 생성하지 않습니다. 로드뷰 이미지와 촬영 정보는 Kakao에 귀속됩니다.
