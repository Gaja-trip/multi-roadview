# 로드뷰 타임

같은 장소의 과거와 현재를 2분할·4분할로 비교하는 **Windows x64 데스크톱 프로그램**입니다. 카카오맵 원본을 각 화면에 독립된 브라우저로 열어, 원본에서 제공되는 실제 촬영 시기를 선택합니다.

## 바로 실행하기

완성된 실행 폴더가 있다면 `release/RoadviewTime-win32-x64/RoadviewTime.exe`를 실행하세요. **폴더 전체를 함께 보관**해야 합니다. Node.js나 API 키 없이 로드뷰를 볼 수 있습니다. 인터넷 연결은 필요합니다.

개발 폴더에서 설치를 마쳤다면 루트의 `로드뷰 타임 실행.cmd`를 더블클릭할 수도 있습니다.

## 사용 방법

1. 왼쪽에서 주소·장소를 검색하고 결과를 선택하거나, **좌표 입력**에 WGS84 위도·경도를 입력합니다.
2. 오른쪽의 모든 화면에서 같은 장소 주변의 카카오맵 로드뷰가 열립니다.
3. 화면 위 **촬영일 선택**을 누르면 원본 화면에서 실제 제공되는 촬영일 목록이 나타납니다. 선택한 한 화면만 해당 시기로 이동합니다. 카카오맵 안의 왼쪽 위 시계·촬영일 메뉴도 사용할 수 있습니다.
4. 위쪽의 **2분할 / 4분할**, 각 화면의 **크게 보기**, **새로고침**, **원본 열기**를 이용하세요.

**지도 링크**에서는 `https://map.kakao.com/…` 또는 `https://kko.to/…` 링크를 모든 화면 또는 지정한 한 화면에 열 수 있습니다. 과거 시점이 포함된 카카오맵 공유 링크를 각 화면에 붙여넣어 비교할 수도 있습니다.

최근 위치와 저장한 위치는 이 PC에 보관됩니다. ‘위치 링크 복사’는 현재 장소의 링크를 복사하며, 모든 화면의 선택 촬영일을 저장하는 기능은 아닙니다. 지도 링크로 이동한 뒤에는 좌표를 추정하지 않습니다.

## 국내 주소 검색 설정 (선택)

기본 주소 검색은 OpenStreetMap Nominatim을 이용합니다. 국내 도로명·지번 주소가 누락될 수 있으므로 검색 결과가 없으면 **좌표·지도 링크로 이동**하거나 카카오 검색을 연결하세요. 서울시청·광화문·강남역·부산역·제주공항은 바로 가기 위치로 제공됩니다.

1. [카카오 개발자 사이트](https://developers.kakao.com/)에서 본인 앱의 카카오맵/로컬 API 사용을 설정하고 **REST API 키**를 확인합니다.
2. 프로그램 왼쪽 아래 **주소 검색 연결 설정**에 키를 입력합니다. JavaScript 키가 아닌 REST API 키를 사용합니다.
3. 키는 Electron `safeStorage`를 통해 Windows 계정으로 암호화해 앱 설정 파일에 저장합니다. 화면과 로그에 키를 다시 표시하지 않습니다.

기본 검색은 사용자가 검색 버튼을 누른 때에만 요청하며, 초당 최대 1회로 직렬화하고 같은 검색어를 세션 동안 캐시합니다. 자동완성·대량 주소 수집 용도로 사용하지 않습니다. 여러 PC에 대규모 배포하는 경우 자체 지오코딩 서버나 계약된 검색 서비스를 사용하세요.

## 설치와 개발

Node.js 22.12 이상과 pnpm이 필요합니다.

```powershell
pnpm install
pnpm start
```

```powershell
pnpm test         # 좌표·링크 허용 범위·화면 경계 검사
pnpm check        # JavaScript 구문 검사
pnpm package      # Node.js가 필요 없는 Windows 실행 폴더 생성
pnpm preview      # http://127.0.0.1:4173 화면 미리보기
```

npm을 사용하는 환경에서는 `npm install`, `npm start`, `npm test`, `npm run package`를 사용할 수 있습니다. Electron 바이너리가 내려받아지지 않은 pnpm 환경에서는 `node node_modules/electron/install.js`를 실행하세요.

브라우저 미리보기는 레이아웃·입력·저장 UI를 확인하는 용도입니다. **브라우저에서 실제 로드뷰와 과거 시점 비교를 제공하지 않습니다.** Windows 프로그램에서 실행하세요. 카카오맵의 프레임 제한을 제거하거나 보안 설정을 끄지 않습니다.

## 제공 범위

- 카카오 공개 지도 API는 [과거 로드뷰 이미지를 제공하지 않는다고 안내](https://devtalk.kakao.com/t/topic/72580)합니다. 본 프로그램은 비공개 과거사진 API 대신 카카오맵 원본의 촬영일 선택 UI를 이용합니다.
- 실제 촬영일, 촬영 지점, 사진 제공 범위는 카카오맵에 따릅니다. 좌표에 촬영 자료가 없으면 주변 도로에서 위치를 조정해 주세요.
- 주소·좌표 이동은 모든 화면에 적용됩니다. **드래그 회전·방향·확대·도로 이동은 각 화면에서 독립적으로 동작**합니다. 주소·좌표를 새로 지정하면 촬영 시기는 다시 선택해야 합니다.
- 촬영일 목록은 카카오맵 원본 UI에 표시된 날짜와 선택기 ID를 읽어 구성합니다. 과거 영상은 원본의 과거사진 비교 기능에서 선택하고, 과거 영상 표시 영역을 확장합니다. 과거 파노라마를 일반 로드뷰 링크로 잘못 열지 않습니다. 비공개 API를 호출하거나 촬영일을 생성하지 않습니다. 카카오맵 화면 구조가 변경되면 원본 화면 안의 날짜 메뉴를 직접 이용하세요.
- 지도에서 로그인하거나 위치 권한을 허용할 필요가 없습니다. 원격 화면에는 Node.js·로컬 파일·앱 IPC 접근 권한이 없습니다.
- 로드뷰 이미지와 촬영 정보는 Kakao에 귀속됩니다. 이미지 수집·재배포 기능은 포함하지 않습니다.
