# 로드뷰 타임 1.1

같은 장소의 과거와 현재를 **하나의 비교 영역**에서 보는 웹·Windows 프로그램입니다. 각 시점은 카카오맵 원본을 사용합니다. 로드뷰 표시에는 API 키가 필요하지 않습니다.

## 사용하기

1. 왼쪽에서 주소·장소명, WGS84 위도·경도 또는 카카오맵 공유 링크로 이동합니다.
2. 오른쪽 위 **2분할 / 4분할**에서 비교 시점 수를 선택합니다. 모든 시점이 같은 비교 영역 안에 표시됩니다.
3. **분할**은 2개 또는 4개 시점을 나란히 배치합니다. **겹침**은 로드뷰를 같은 크기로 포개고 경계로 나눠 표시합니다. 4시점에서는 가로·세로 경계 또는 가운데 손잡이를 움직입니다. 아래 슬라이더와 방향키도 사용할 수 있습니다.
4. 각 시점의 **⛶ 크게 보기**에서 원본 왼쪽 위 촬영일·시계 버튼을 눌러 과거 사진을 선택합니다. 카카오맵이 과거 사진의 썸네일을 표시하면 **비교** 버튼을 누릅니다. 원본의 비교 경계를 오른쪽 끝으로 옮기면 과거 사진만 볼 수 있습니다. **비교로 돌아가기**로 전체 비교에 복귀하세요.
5. **메뉴 숨기기 / 메뉴 보이기**로 왼쪽 패널을 접고 펼칩니다. 선택은 이 브라우저 또는 PC에 저장됩니다.

시점 A·B·C·D는 보기 전환 시 다시 생성하지 않으므로 선택한 촬영일과 방향을 유지합니다. 주소·좌표·링크 이동이나 새로고침은 원본을 다시 불러오므로 촬영일을 다시 골라야 합니다. 2분할에서 감춘 C·D도 4분할로 돌아오면 유지됩니다.

왼쪽 아래 일반 지도는 표시 영역 밖으로 숨겼습니다. 웹에서는 원본 프레임의 아래 220px을 잘라 표시하는 방식이므로 원본의 일부 하단 조작부도 보이지 않습니다. 원본 지도는 각 시점의 **© Kakao ↗** 링크로 열 수 있습니다. 촬영일·방향·확대는 원본에서 조절하며, 서로 다른 시점의 방향·지점이 자동으로 일치하지는 않습니다.

## 웹 실행 및 Vercel 배포

```powershell
node scripts/preview.mjs
# http://127.0.0.1:4173
node scripts/build-web.mjs
```

저장소를 Vercel 프로젝트에 연결하고 재배포하세요. 루트의 `vercel.json`이 웹 빌드와 `dist` 출력, `/api/search` 서버 함수를 설정합니다. 웹 빌드는 Electron 설치 없이 실행됩니다. 프로젝트 Root Directory는 이 저장소 루트로 지정하세요. 배포 파일은 `dist`만 수동 업로드하면 주소 검색 함수가 빠지므로 **전체 저장소로 배포**해야 합니다.

이전 웹 버전은 미리보기만 표시했습니다. 현재 버전은 HTTPS 카카오맵 원본을 iframe으로 실제 표시하며, 앱의 CSP에서 해당 프레임을 허용합니다. 외부 서비스가 프레임 제공 방식을 바꾸거나 네트워크가 차단하면 표시가 달라질 수 있습니다.

## Windows 실행

`release/RoadviewTime-v1.1.0-win32-x64/RoadviewTime.exe`를 실행하세요. 실행 폴더 전체를 보관해야 합니다. 기존 1.0 실행 파일은 자동 업데이트되지 않습니다.

개발 환경에서는 Node.js 22.12 이상과 pnpm으로 다음 명령을 사용합니다.

```powershell
pnpm install
pnpm start
pnpm test
pnpm check
pnpm build
pnpm package
```

설치한 개발 폴더의 `로드뷰 타임 실행.cmd`로도 실행할 수 있습니다. Electron 바이너리가 없으면 `node node_modules/electron/install.js`로 설치합니다.

## 주소 검색 설정

기본 검색은 OpenStreetMap Nominatim과 대표 장소 바로 가기를 사용합니다. 국내 검색 결과가 없으면 좌표·카카오맵 링크로 이동하거나 카카오 REST 검색을 연결하세요.

- Windows: 왼쪽 아래 **주소 검색 연결 설정**에 본인 카카오 REST API 키를 입력합니다. Windows 계정으로 암호화해 저장합니다.
- Vercel: 프로젝트의 환경 변수 `KAKAO_REST_API_KEY`에 본인 REST API 키를 설정하고 재배포합니다. 서버에서만 사용하며 웹 번들에는 포함하지 않습니다. 키가 없어도 로드뷰는 표시됩니다.

공개 기본 검색은 수동 검색에만 사용하며, 캐시와 인스턴스별 요청 간격을 적용합니다. 여러 사용자가 동시에 사용하는 공개 서비스에는 계약한 검색 서비스 또는 자체 검색 서버를 연결하세요.

최근·저장 위치는 현재 브라우저 또는 PC에 보관됩니다. 위치 링크 복사는 좌표·지도 링크를 복사하며 각 시점의 선택한 촬영일을 저장하지 않습니다.

## 원본 데이터

촬영일·과거 사진·촬영 지점은 카카오맵에서 실제 제공하는 범위만 이용합니다. 원본의 촬영일을 확인해 주세요. 카카오 공개 API가 제공하지 않는 과거 사진 목록을 생성하거나 비공개 API로 수집하지 않습니다. 로드뷰 이미지와 촬영 정보는 Kakao에 귀속됩니다.
