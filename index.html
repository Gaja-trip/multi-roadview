A SMALL WINDOW TO THE PAST

시간을 나란히 놓는 방법

01
궁금한 장소로 이동하세요.

주소·장소를 검색하거나 WGS84 위도·경도, 카카오맵 링크를 입력하세요. 모든 화면이 같은 장소로 이동합니다.

02
화면마다 촬영 시기를 고르세요.

로드뷰 왼쪽 위의 시계·촬영일 메뉴에서 실제 제공되는 시기를 선택하세요. 과거 사진을 선택하고 원본의 비교 버튼을 누른 뒤, 원본 경계를 오른쪽 끝으로 옮기면 과거 사진만 크게 볼 수 있습니다.

03
2분할 또는 4분할로 비교하세요.

2분할·4분할 모두 같은 비교 영역을 사용합니다. 겹침에서는 가로 경계와 세로 경계(4분할)를 움직여 비교하세요. 각 시점의 크게 보기에서 촬영일과 방향을 조절한 뒤 비교로 돌아오세요.

촬영일과 과거 사진의 제공 여부는 장소마다 다릅니다. 로드뷰에 표시되는 촬영일을 기준으로 확인해 주세요. 위치를 새로 이동하면 각 화면의 촬영 시기는 초기화됩니다.

더 정확한 국내 주소 검색

기본 검색은 OpenStreetMap을 이용합니다. 도로명·지번 주소와 국내 장소를 더 정확히 찾으려면 카카오 REST API 키를 연결하세요.

기본 주소 검색 사용 중

로드뷰를 보는 데에는 API 키가 필요하지 않습니다.
키는 Windows 암호화 저장소로 보호해 이 PC에 저장합니다.
